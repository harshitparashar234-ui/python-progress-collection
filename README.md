
# Python Programs Collection

A beginner-friendly collection of Python programs created to practice basic programming concepts and data handling.

## Programs Included

### 1. Factorial Calculation
Calculates the factorial of a non-negative integer using a loop.

### 2. Fibonacci Series
Generates the Fibonacci series for the number of terms entered by the user.

### 3. Structure-to-Dictionary Conversion
Demonstrates how student information stored in a Python object can be converted into a dictionary using `vars()`.

## Technologies Used
- Python 3
- Classes and Objects
- Loops
- Dictionaries

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run any program using:

```bash
python factorial.py
python fibonacci.py
python structure_to_dictionary.py
```
